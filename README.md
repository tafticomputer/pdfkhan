# پی‌دی‌اف‌خوان (PdfKhan)

برنامه‌ی اندروید برای خواندن فایل PDF با صدای فارسی:

1. فایل PDF را انتخاب می‌کنید.
2. صدای فارسی را انتخاب می‌کنید.
3. دکمه‌ی «پخش» را می‌زنید و برنامه متن را می‌خواند (با نمایش بخش در حال خواندن، توقف موقت، ادامه، تنظیم سرعت و انتخاب صفحه‌ی شروع).

## ساخت APK در گیت‌هاب

1. یک مخزن (Repository) جدید در GitHub بسازید.
2. همه‌ی فایل‌های این پروژه (از جمله پوشه‌ی مخفی `.github`) را در شاخه‌ی `main` آپلود/Push کنید.
3. در تب **Actions** مخزن، workflow با نام **Build APK** خودکار اجرا می‌شود (یا با «Run workflow» دستی اجرایش کنید).
4. پس از پایان (حدود ۴ تا ۸ دقیقه) APKها در بخش **Releases** مخزن (سمت راست صفحه‌ی اصلی مخزن) با نام «آخرین نسخه» قرار می‌گیرند. از همان‌جا مستقیم دانلود کنید؛ این دانلود قابل ازسرگیری است. دو فایل هست:
   - `PdfKhan-arm64-v8a.apk` ← برای اکثر گوشی‌ها (حدود ۳۰ مگابایت)
   - `PdfKhan-armeabi-v7a.apk` ← فقط برای گوشی‌های خیلی قدیمی ۳۲ بیتی
5. (اختیاری) برای انتشار با شماره‌ی نسخه، یک تگ بسازید، مثلاً `v1.0`:

```bash
git tag v1.0
git push origin v1.0
```

## صدای فارسی

- **صداهای داخلی برنامه** (مدل‌های Piper فارسی با موتور Sherpa-ONNX): برای حفظ کوچک بودن APK، داخل آن نیستند. اولین بار که یکی را انتخاب و «پخش» را بزنید، برنامه حدود ۶۷ مگابایت دانلود می‌کند و بعد از آن کاملاً آفلاین کار می‌کند. اگر اینترنت قطع شود، دوباره «پخش» را بزنید؛ دانلود از همان‌جا ادامه می‌یابد.
- **صداهای گوشی**: اگر روی گوشی صدای فارسی نصب باشد (تنظیمات ← «تبدیل متن به گفتار» ← Google Speech Services)، آن‌ها هم در فهرست می‌آیند.
- برای افزودن صدای دیگر، یک سطر به `VoiceCatalog` در `VoiceDownloader.kt` اضافه کنید (مثلاً `vits-piper-fa_IR-reza_ibrahim-medium`).
- مدل‌های Piper فارسی برای استفاده‌ی شخصی مناسب‌اند؛ پیش از انتشار عمومی یا تجاری، مجوز هر مدل (فایل MODEL_CARD) را بررسی کنید.

## OCR فارسی

صفحه‌هایی از PDF که متن ندارند (اسکن‌شده) خودکار تصویر می‌شوند و با Tesseract (داده‌ی `fas`) خوانده می‌شوند. اگر متن خوانده‌شده از یک PDF خراب یا نامفهوم بود، گزینه‌ی «OCR برای همه‌ی صفحه‌ها» را روشن کنید. OCR برای هر صفحه چند ثانیه طول می‌کشد.

## محدودیت‌ها

- کیفیت OCR به وضوح اسکن بستگی دارد؛ متن دست‌نویس یا اسکن بسیار ضعیف خوب خوانده نمی‌شود.
- اگر در PDFی کلمات برعکس خوانده شد، گزینه‌ی «اصلاح متن معکوس» را فعال کنید.
- حین خواندن، صفحه روشن می‌ماند.

## ساخت محلی (اختیاری)

ابتدا فایل‌های حجیم را دانلود کنید (یک‌بار)، سپس با Android Studio پوشه را باز کنید، یا با Gradle 8.7 و JDK 17:

```bash
bash scripts/fetch_assets.sh
gradle assembleDebug
```
